# Project 1: AWS EC2 + Nginx Web Server

## 1. Project Goal
I launched an Ubuntu server on AWS and hosted a simple website using Nginx.

Hindi: Maine AWS par Ubuntu server banaya aur Nginx ki help se website chalayi.

## 2. Services and Tools
- AWS EC2: A virtual computer in the cloud.
- Ubuntu: The operating system on my server.
- Nginx: Software that serves my website.
- Security Group: Controls incoming network traffic.

## 3. What I Did
1. Launched an EC2 instance.
2. Connected to the server.
3. Installed Nginx.
4. Started and checked the Nginx service.
5. Created a custom webpage.
6. Allowed HTTP traffic on port 80.
7. Opened the website using the public IP address.

## 4. Key Learnings
- EC2 provides a virtual server.
- Nginx serves website content.
- Port 80 is commonly used for HTTP.
- Security Groups control access to the server.

## 5. Project Status
Completed as a hands-on learning project.

- Learn HTTPS.
